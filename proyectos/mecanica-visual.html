El proyecto

Prototipo visual de gestión de taller con módulos, ventanas de trabajo y vista previa de fotografías. Incluye formularios de ingreso e inspección.

Ayuda a evaluar cómo registrar y consultar una atención de taller desde la interfaz. Las referencias visuales a bases de datos no acreditan una persistencia implementada.

Funciones principales

  • Navegación entre páginas internas
  • Apertura y cierre de modales
  • Previsualización de fotografías
  • Formularios de ingreso e inspección

Alcance del proyecto

Las secciones de Supabase y SQLite son elementos de interfaz. Este HTML no acredita sincronización o persistencia backend.
