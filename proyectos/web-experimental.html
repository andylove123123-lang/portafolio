El proyecto

Colección de catálogos web para distintos tipos de comercios, con productos, carrito y animaciones de entrada.

Explora cómo adaptar una experiencia de compra a muebles, panadería, farmacia, veterinaria o carnicería. El carrito conserva su selección en el navegador; los datos son demostrativos y no se procesan pagos.

Funciones principales

  • Páginas temáticas para cinco sectores
  • Carrito con altas y eliminación
  • Persistencia del carrito en el navegador
  • Diseño con animaciones de aparición

Alcance del proyecto

Son demostraciones visuales con contenido de muestra; no se reproducen testimonios ni cifras ficticias. No se acredita una pasarela de pago.

Evidencia técnica

Referencias del código revisado; los archivos originales permanecen privados.

  • PAGINA WEB EXPERIMENTAL/script.js: addToCart, removeFromCart, saveCart, checkout
  • PAGINA WEB EXPERIMENTAL: index, panaderia, farmacia, veterinaria y carniceria
