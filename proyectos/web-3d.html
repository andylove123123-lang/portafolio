El proyecto

Página de presentación construida con Three.js y animaciones vinculadas al desplazamiento mediante GSAP ScrollTrigger.

Explora una forma inmersiva de presentar servicios con escenas y secciones animadas. Las menciones a ERP, aplicaciones móviles o predicción son contenido de presentación, no productos implementados por esta página.

Funciones principales

  • Renderizado de escena con Three.js
  • Animaciones con GSAP y ScrollTrigger
  • Secciones de presentación de servicios

Alcance del proyecto

Se acredita la experiencia visual. Las tarjetas de ERP, predicción o aplicación móvil no prueban que esos sistemas estén implementados dentro de este proyecto.
