El proyecto

Sistema para organizar clientes, vehículos, órdenes de trabajo y repuestos de un taller. Su estructura incorpora persistencia y módulos de comprobantes y licencias.

Reúne información del vehículo y del trabajo para consultar el seguimiento de una atención. Las integraciones externas y el alcance fiscal de los comprobantes requieren validación independiente.

Funciones principales

  • Registro y consulta de clientes y vehículos
  • Creación y listado de órdenes de trabajo
  • Registro de repuestos e inventario
  • Registro de facturas en la base de datos
  • Ruta de reconocimiento de placas mediante un servicio externo

Alcance del proyecto

La autenticación y los permisos no se validaron. El reconocimiento de placas depende de un servicio externo. Registrar facturas no implica emitir comprobantes electrónicos autorizados.

Evidencia técnica

Referencias del código revisado; los archivos originales permanecen privados.

  • main.py: crear_cliente, registrar_vehiculo, crear_orden, agregar_repuesto, crear_factura
  • static/js/app.js: cargarVehiculos, guardarNuevaOrden
