El proyecto

Aplicación de reservas que organiza sucursales, servicios, días y horarios disponibles. Incluye herramientas de administración de disponibilidad y calendario.

Guía la solicitud de una cita y contempla validaciones y actualizaciones de disponibilidad. Las capturas permiten revisar el recorrido sin crear reservas reales ni confirmar servicios externos.

Funciones principales

  • Selección de sucursal y servicio
  • Calendario y consulta de disponibilidad
  • Validación del formulario de reserva
  • Administración de sucursales, servicios y horarios
  • Actualización de reservas mediante suscripción

Alcance del proyecto

El código actual usa Supabase. Algunas indicaciones del README describen una integración n8n anterior y no se toman como evidencia de funcionamiento actual. Necesita configuración y permisos de la base de datos.

Evidencia técnica

Referencias del código revisado; los archivos originales permanecen privados.

  • app.js: renderCalendario, cargarDisponibilidad, validarFormulario, escucharCambiosEnReservas
  • mnt/user-data/outputs/spa-boutique/admin/app.js: cargarReservas, agregarSucursal, editarPrecioServicio
